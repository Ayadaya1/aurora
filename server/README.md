# Formula OCR API

Запуск: `python -m uvicorn server:app --host 0.0.0.0 --port 8000 --workers 1`.
Установить зависимости из `requirements.txt`. PaddlePaddle/PaddleX закреплены
на проверенных версиях 3.3.1/3.7.2. При первом запуске скачивается модель
PP-FormulaNet_plus-M. Готовность: `GET /health`, возвращает 200 только после
загрузки модели и прогрева. Контракт `POST /recognize` сохранён: multipart
`image`, `mode=photo|drawing`, ответ `{"latex": "...", "mode": "..."}`.

## Настройки

- `FORMULA_CPU_THREADS=2`: выбран замером на сервере с 4 vCPU. При смене машины
  повторите замер, больше потоков не обязательно быстрее.
- `FORMULA_MODEL_NAME=PP-FormulaNet_plus-M`, `FORMULA_DEVICE=cpu`.
- `FORMULA_INFERENCE_TIMEOUT=30`, `FORMULA_STARTUP_TIMEOUT=120` секунд.
- `FORMULA_QUEUE_TIMEOUT=10`: ожидание занятой модели, затем HTTP 503/Retry-After.
- `FORMULA_CACHE_SIZE=32`: LRU для результатов одинаковых байтов изображения
  и режима. Изображения не сохраняются в кэше. `0` отключает кэш.

Используйте **один Uvicorn worker**: каждый процесс загружает отдельную модель.
Нейросеть работает в отдельном spawn-процессе. После тайм-аута он завершается,
а следующий запрос создаёт новый. Перезапуск не блокирует event loop API.

Изображения передаются модели в памяти в формате BGR без промежуточного PNG.
EXIF-поворот применяется до распознавания; прозрачность накладывается на белый
фон. У рисунков обрезаются пустые поля с сохранением отступа; фотографии не
обрезаются и не бинаризуются. Ограничения: 10 МиБ, 20 млн пикселей, длинная
сторона перед моделью — максимум 2048 пикселей. Пустой рисунок возвращает 400.

## Проверки и замеры

```bash
python -m unittest -v
for threads in 10 4 2 1; do python benchmark_cpu.py "$threads"; done
```

21 сентября 2026, 4 vCPU, CPU, прежняя модель: три синтетических изображения
(линейное уравнение, дробь, мелкая формула на большом холсте), два замера после
первого прогрева. Среднее время: 10 потоков — 3,706 с; 4 — 2,800 с;
2 — 2,685 с; 1 — 4,137 с. LaTeX совпал во всех случаях.

Через API после изменений: первый запрос 2,49–2,84 с, повторный запрос
1,9–2,4 мс на localhost благодаря кэшу. До изменений прозрачный PNG с `x+1=2`
ошибочно распознавался как другая формула; после исправления — `x+1=2`.
Это небольшой регрессионный набор, а не оценка точности на реальных фото
и рукописных формулах. Новая модель не обучалась и не подменялась.

`aurora-formula.service` содержит настройки текущего сервера. Для другого
размещения измените WorkingDirectory/ExecStart и пользователя сервиса.
